## 一、角色現況

- Runchar，Lv1，身上 0 美拉，記憶點數剩 40。
- 上限：生命 339、法力 414、移動力 373、內力 150。
- 已學 23 項，都已在 Lv1 免費練到「十分熟練」（多半 71～81，拳力（bare fist）51）。明細見 `#quest 新手開局`。
- 已確認的遊戲規則：
  - Lv1 練習（prac）不收美拉，一直練到「你對 X 這個技能十分熟練了」為止；之後只能靠使用提升。升級後每練一次要 132～728 美拉。
  - 製造食物術（create food）變出乾糧（magic food），要 `get food` 再 `eat food`；造泉術（create spring）變出飲水機（spring），不能撿、過一會兒會乾掉。各花 20 法力。
  - 飢餓「你飢餓難耐」、口渴「你口乾舌燥」、走不通「這個方向沒有路喔!」。
  - 市中心的敘述寫著「新手請鍵入 start 按下 [enter] 進入新手之旅」。

## 二、程式新增的指令

| 指令 | 做什麼 |
|---|---|
| `#map <地點或路線> [房間數] [深度]` | 先照路線走到起點（路線上的房間也記進地圖），再只探索起點附近「深度」步以內的房間。地點可以寫區域名稱（`勇者學校`）、練功設定名稱（`矮人王國南`）或路線（`map3 s`）。不寫地點時從目前位置（或回城點）開始 |
| `#learn <技能> [pay]` | 用地圖找到教這個技能的雕像，走過去 `look statue` 確認、`learn statue <技能>`、一直練到十分熟練；遊戲說「你得先學 X」會先去學 X。要花錢的練習只在加 `pay` 時才做 |
| `#next all` | 解謎自動一步接一步，遇到要你自己處理的步驟或出問題才停 |
| `#quest 學大地之斬` | 新的解謎：查條件 → 向圓桌騎士巨像學 → 學不了就走騎士堡 |
