# 入門與升級路線

## 連線與建立角色

- 位址：`void7777.ddns.net`，port `7777`（telnet）。推薦使用 zMUD 或現代 MUD client，也可以用本專案的練功程式。
- 建立角色：輸入英文名字 → 出現「你確定要用XXXX這個ID了嗎?(Y/N)?」輸入 Y → 設定密碼 → 選擇性別（男性 M／女性 F／中性 N，不影響遊戲）→ 按 Enter 進入遊戲。
- 進入遊戲後先設定提示列，方便隨時掌握狀態（練功程式也靠它判斷血量）：

```
prompt <生命%h/%H 法力%m/%M 移動力%v/%V 內力%p/%P>
```

## 升級的基本觀念

- 7777 以 level 60 為起點，一開始要做的事就是升級。在 `/wwsunnnwwu` 處可以依記憶容量學技能；在 TP-??（`/sswu`）處可以 train 屬性和 changebody。
- 經驗值來自戰鬥中以及殺死怪物後，盡量找比自己高約 9 級的 mob。不確定打什麼加最多 exp 時多用 `con`：出現「他將譏笑你的無知」（雙方差約 5～10 級）代表這隻 mob 現在加最多 exp。要知道怪物等級可以學 lore。
- 低等級時低階技能反而比高階好用，例如低等級時 saulinfist 比 lohanfist 好用。
- 後期光靠小拳法、小劍法不夠，通常建議學 earthslice（大地之斬）。它會消耗移動力，所以要想辦法提高 MV：學一些劍法或某些法術都會增加移動力。
- 升級速度：大地之斬 ＞ 絞殺 ＞ 拳法。
- 其他可以升級的地方可以在遊戲裡打 `area` 查詢。

## 新手流程

### Lv1：先在新手學校學技能

新角色的記憶容量只有 800 點，學技能會扣點數（`practice` 會顯示「你還剩下 N 點的記憶容量」）。原攻略寫「Lv1 practice 不消耗記憶點數」，2026-10-29 實測並非如此。建議的 800 點分配見解謎〈新手開局〉（程式裡 `#quest 新手開局`）。

勇者學校的大堂是雕像館入口：北面是冒險者館，東面是東方技巧（拳法家巨像在東北、盜帥巨像在東南），西面是西方技巧（牧師、教宗、力場系巫師、大冒險家巨像）。在雕像前 `look statue` 看它教什麼，學法是 `learn statue 技能名` → `prac 技能名`（不用加引號，例如 `learn statue cure light`）。

### Lv1～9：新手之旅

- 路線：`/2sw2u` 到新手學校，輸入 `start` 進入新手之旅。
- stage 1～5 依序過關，可升到 Lv9，過關獎賞是上帝武裝 (god vest)。

### Lv10～30：格鬥天堂

格鬥天堂是 Lv10～30 最有效率的練功場所，共有 12 間戰鬥模擬室。

- 路線：`/3w2s5e2se` → `open e` → `e` → `talk paradiser ok` → `get key`
- 從 paradiser 處：`2w2n3w6n` → `unlock d` → `open d` → 進入戰鬥模擬室
- 12 間練功房，打完 [1] 換隔壁 [2]，依此類推。
- Lv12 前用少林拳 (`f saulin mob`)，之後換羅漢拳 (`f lohan mob`)；打怪前先 `agg 100`。

### Lv30～35：學大地斬

- 找線上玩家帶你去騎士堡亞瑟王處學 earthslice（大地之斬），詳見解謎〈騎士堡〉。
- 用法：`ear <怪的id>`，可配合 `agg 0` 提高閃躲。
- 可去矮人王國練級：`/3w3se` → `look painting` → `s5wnd3n`。

### Lv35～60：元素峽谷

元素峽谷是群攻天堂，earthslice 可一次打多隻怪物。

- 路線：`/3w3se` → `look painting` → `s` → 往 `e` 走到底。
- 有（白色聖光）的怪先不打；遇到 5～6 隻怪時效率特別高。
- 帶大補丸、頭好壯壯（在 `/ws` 購買）。
- 沒怪時 recall 等 reborn、sleep 回 mana；看到「你感覺到周圍有點風吹草動.」代表怪物已經重生。

### Lv60 以後

練滿技能 → 逛區域湊裝備 → 組隊解 all quest → 打 war 賺戰功 → 練多隻角色玩遍所有職業。

## 熱門練功區說明

**夢幻撲克王國**：Lv10～20 只打黑桃兵 (spade)，只有這種 mob 加的 exp 多。Lv20～30 通殺，但要依花色順序：黑桃 (spade) → 方塊 (diamond) → 紅心 (heart) → 梅花 (club)；jack、queen、king 等大型 mob 則依黑桃 → 方塊 → 梅花 → 紅心。

**天界**（Lv45～60）：mob 等級 40～60，數量多又密集，是組隊練級首選。可以讓牧師幫 mob 補血無限循環：

1. 用會 charm 的角色抓童子 (retinue) 和日光、月光菩薩（lv60 以下才抓得到）。
2. 把抓到的 mob group 起來，讓他們成為隊伍的一份子。
3. 這隻角色再跟牧師 group，牧師就能一次幫這些 mob 全補滿 hp。
4. retinue 要 lv55 以上才能 group（group 範圍是自己等級 ±5）。
5. 記得幫 mob 上聖光，不然很容易被殺死。

**吉雅尼斯王城**（Lv55～60）：代表 mob 是珠寶商 (jeweller)、烘焙師父 (baker)、巫師 (wizard)、梅傑特 (mayato)。珠寶商比較安全；烘焙師父物攻約珠寶商的 2～3 倍；巫師和梅傑特法術很猛（nuc 沒有 san 時 16xx～19xx）。

**哈爾比之家**（`/9w4sdw2nue3u`）：無謎，適合 baby 升級；有迷霧不可 recall，耗 mv。也是練 holy 的第二選擇：打死一隻 harpy 心地 +4。

## 新手升級提示

1. 已經拿到 low level eq 時，先把 lv1 的 eq 和 coins 放在地上，再申請一隻新角色。
2. 撿到 eq 後裝備好，remove knife 和 magazine，再 `agg 100`。
3. 到 school 先找機器人 changebody：攻擊型 22 14 14 22 18、train 8 0 0 8 4；法術型 14 22 14 18 22、train 0 8 0 4 8。
4. 找 statue 學 buttock 和 hanging 後先到動物園升級，絞殺一隻就能到 lv2。
5. 重複補充 eq，直到屬性穿滿為止。
6. Lv10 左右可學 earthslice（提前學也可以，但 ear 一定要十級以後才能用）。學成後裝備武器、agg 改為 0，同時 cancel 絞殺，改學劍法和 fly、refresh、full refresh 等法術增加 move。點數夠時可以學陣法讓 MV 大增。
