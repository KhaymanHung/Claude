# 四度空間 7777 攻略（整理版）

本文件整理自〈7777 MUD 全方位攻略指南〉（四度空間完整指南 V1），原文彙整了 7777.doc、7777Quest.docm（破粹虛空 V5.0 解謎攻略與擴充版）以及 PTT MUD 看板的職業配法系列文（placewind、motonpom 等作者）。

這一版做了三件事：

- **統一格式**：所有表格、步驟、路線改用同一種寫法；解謎一律分成「路線、需要、獎勵、步驟、提示」。
- **去除重複**：原文中重複出現的段落合併成一處，例如升級地點（原本出現三次）、愛莎尼亞與野蠻遊戲（各出現兩次）、職業說明與 PTT 配法、兩份 Power Baby 穿法、Delay 規則、投擲與暗器、攻擊企圖心。
- **資料化**：區域、解謎、技能法術、裝備都存成 `data/` 底下的資料檔，練功程式直接使用。本文件的解謎、區域、技能表、裝備表都是從這些資料檔產生的，修改資料後執行 `python tools/build_guide.py` 就能重新產生文件。

## 路線寫法

| 寫法 | 意思 |
|---|---|
| `/` | recall，回到風采之都市中心 |
| `3w2s` | 往西 3 步、往南 2 步（n 北、s 南、e 東、w 西、u 上、d 下） |
| `map2` | 到古代東方大陸：`/3w4s` 後 `talk wizard help` |
| `map3` | 到西方大陸：`/3w3se` 後 `look painting` |
| `open e`、`talk man 幫助` | 一般遊戲指令，照打即可 |

## 在練功程式裡使用

每個解謎、區域、技能、裝備都可以在程式裡直接查詢或執行，例如 `#quest 五行世界`、`#goto 魔谷`、`#skill 降龍`、`#item 元素之戒`、`#farm 泰洛市`。完整指令列表見最後一章。

> 7777 的謎題和區域可能隨版本變動；若發現與本文不同，以遊戲內提示為準。標示「資料不完整」的部分是原攻略就缺少的。
