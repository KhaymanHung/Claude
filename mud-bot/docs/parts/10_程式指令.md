# 練功程式指令速查

在練功程式（`python main.py`）裡，以 `#` 開頭的是程式指令，其他文字直接送到遊戲。

| 指令 | 作用 | 範例 |
|---|---|---|
| `#find <關鍵字>` | 搜尋區域、解謎、技能、裝備 | `#find 元素之戒` |
| `#area <名稱>` | 區域的等級、路線、相關解謎、練功設定 | `#area 企鵝村` |
| `#skill <名稱>` | 技能或法術的記憶量、前置、學習順序、學習對象 | `#skill 降龍` |
| `#item <名稱>` | 裝備的屬性、取得方式、相關解謎 | `#item 魔法手套` |
| `#goto <名稱或路線>` | 走到區域或解謎地點；也可以直接給路線 | `#goto 魔谷`、`#goto map3 s6e7n` |
| `#quest <名稱>` | 開始解謎，顯示說明和第一步 | `#quest 五行世界` |
| `#next` | 執行目前這一步並前進；要自己處理的步驟就是「完成，下一步」 | |
| `#next all` | 自動一步接一步，遇到要自己處理的步驟、標示暫停的步驟或出問題才停 | |
| `#learn <技能> [pay]` | 自動走到教這個技能的雕像學會並練到十分熟練；遊戲要求先學別的技能時會先去學。要花錢的練習只在加 pay 時做。需要先 `#map 勇者學校 80 10` | `#learn 夜視術`、`#learn earthslice` |
| `#map <地點或路線> [房間數] [深度]` | 先走到起點再探索附近；記下房間、怪／NPC（consider）、物品、商店（list）到 data/live/ | `#map 勇者學校 80 10`、`#map 矮人王國南 60 8`、`#map / 300 15` |
| `#survey`、`#survey help` | 收集指令輸出和所有 help 到 data/live/ | |
| `#skip [n]`、`#step [n]` | 跳過步驟、重看或跳到第 n 步 | `#step 3` |
| `#quest list`、`#quest stop` | 列出全部解謎、結束目前的解謎 | |
| `#farm <名稱>` | 用攻略的練功設定前往並開始打怪；`#farm list` 列出全部 | `#farm 泰洛市` |
| `#auto` | 用 config.toml 的 [hunt] 設定開始或停止狩獵 | |
| `#record`、`#record save <名稱>` | 記錄你手動走的路，存成自訂路線；名稱和練功設定相同時會當作巡邏路線 | `#record save 泰洛市` |
| `#stop` | 停止狩獵和走路線 | |
| `#status` | 狀態、擊殺數、每小時經驗、目前解謎進度 | |
| `#reload` | 重新讀取設定檔和攻略資料 | |

解謎的步驟有三種：學技能的步驟（learn），`#next` 會呼叫 `#learn`；有指令的步驟，`#next` 會照順序送出（走路時遇到「走不過去」會停下來）；打王、走迷宮、等時間這類步驟標示為「自己處理」，程式只顯示說明，完成後再 `#next`。
