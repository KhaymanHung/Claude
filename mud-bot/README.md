# 四度空間 MUD 練功與解謎助手（MERC 2.2）

用 Python 直接連上四度空間（不需要 zMUD），可以：

- **自動練功**：沿路線或在練功區原地打怪，血量太低就逃跑回城，hp／mv 不夠就睡覺補滿。
- **查攻略**：搜尋區域、解謎、技能、裝備，例如「元素之戒怎麼拿」「降龍要先學什麼」。
- **照攻略走**：`#goto 魔谷` 自動走過去；`#quest 五行世界` 逐步帶你解謎。
- **攻略文件**：`docs/四度空間攻略.md` 和 `.docx` 是整理過、統一格式、去除重複的完整攻略。

## 需求

- Python 3.11 以上（程式只用標準函式庫，不需要 `pip install`）
- 重新產生 Word 版攻略時才需要 [pandoc](https://pandoc.org/)

## 開始使用

1. `config.toml` 的 `host` 已經填了攻略上的位址 `void7777.ddns.net`，port 7777。
2. 執行 `python main.py`，連上後先在遊戲裡設定狀態列（程式靠它判斷血量）：
   ```
   prompt <生命%h/%H 法力%m/%M 移動力%v/%V 內力%p/%P>
   ```
3. 試試 `#find 元素之戒`、`#skill 降龍`、`#area 企鵝村`。

## 指令

以 `#` 開頭的是程式指令，其他文字直接送到遊戲。

| 指令 | 作用 |
|---|---|
| `#find <關鍵字>` | 搜尋區域、解謎、技能、裝備 |
| `#area <名稱>` | 區域的等級、路線、相關解謎、練功設定 |
| `#skill <名稱>` | 記憶量、前置、完整學習順序與總點數、學習對象、互斥技能 |
| `#item <名稱>` | 裝備屬性、取得方式、相關解謎、出現在哪些配裝 |
| `#goto <名稱或路線>` | 走到區域或解謎地點，例如 `#goto 魔谷`、`#goto map3 s6e7n` |
| `#quest <名稱>` | 開始解謎；`#next` 執行目前步驟、`#skip` 跳過、`#step n` 跳到第 n 步、`#quest list`、`#quest stop` |
| `#farm <名稱>` | 用攻略的練功設定前往並打怪；`#farm list` 列出全部 |
| `#auto` | 用 `config.toml` 的 `[hunt]` 開始或停止狩獵 |
| `#record` | 記錄你手動輸入的指令；`#record save <名稱>` 存成路線 |
| `#stop`、`#status`、`#reload`、`#help`、`#quit` | 停止、狀態、重新載入、說明、離開 |

### 解謎怎麼進行

`#quest 名稱` 會先顯示謎題說明（路線、需要的物品、獎勵、附表），再顯示第一步。每一步有兩種：

- **有指令的步驟**：`#next` 會依序送出（走路遇到「走不過去」會停下來提示你）。
- **自己處理的步驟**：打王、走迷宮、等時間這類需要判斷的部分，程式只顯示說明，你完成後再 `#next`。

### 練功怎麼進行

`#farm 泰洛市` 會回城、走到練功區，然後依 `config.toml` 的規則打怪、逃跑、休息。攻略只寫了怎麼走到練功區，沒有寫區域裡的巡邏路線，所以：

- 沒有巡邏路線時，會在到達的那一格清怪，等怪重生再打。
- 想巡邏的話，第一次自己走一圈：`#record` → 走路 → `#record save 泰洛市`，之後 `#farm 泰洛市` 就會照這條路巡邏。

## 要依實際遊戲調整的地方

`config.toml` 裡標記 `TODO` 的地方。最重要的是 `[messages]`：目前是 MERC 原版的英文訊息，加上攻略裡出現過的少數中文訊息。四度空間是中文化的，請把實際看到的中文訊息（例如殺不到人、怪死掉、逃跑成功、走不過去）貼給 Claude，或自己用 `|` 加進去。訊息比對不到時，狩獵和走路線都無法正確判斷狀況。

## 更新攻略

- 改資料：編輯 `data/` 底下的檔案（格式見 `data/README.md`），程式裡 `#reload` 就會套用。
- 改敘述章節：編輯 `docs/parts/*.md`。
- 重新產生文件：`python tools/build_guide.py --docx`

## 離線測試

```
python tools/fake_mud.py      # 視窗一：啟動模擬伺服器
python main.py                # 視窗二：config.toml 的 host 改成 127.0.0.1
```

模擬地圖：神殿往北是廣場、森林（老鼠 rat）、洞穴（主動攻擊的哥布林 goblin）；往其他方向是到處都走得通的荒野，可以測試 `#goto` 和 `#quest` 的長路線。

## 注意

使用前請先確認四度空間對自動練功／robot 的規定。
